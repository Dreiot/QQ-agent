# 群管理节点目录

目录包含 109 种节点，其中 106 种显示在默认库；其余只兼容已有规则。执行线控制运行顺序，数据线连接独立字段。自动 / 已填不需要额外连线；必填可手动填写或连线。

## 消息判断

### 消息匹配

按文字、图片、语音、提及、回复、转发或网址等条件检查触发消息。是和否只会选择一侧。

- 执行方式：是 / 否分支
- 例如：包含“广告” → 是：撤回消息；否：结束

| 数据输入 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| 待检查文字 | `content` | 文字 | 自动沿用当前流程，无需连线 |
| QQ 号 | `user_id` | QQ 号 | 自动沿用当前流程，无需连线；允许缺失；默认收起 |
| 群号 | `group_id` | 群号 | 自动沿用当前流程，无需连线；默认收起 |
| 匹配方式 | `match` | 文字 | 可手动设置 |
| 查找内容（文字匹配时必填） | `text` | 文字 | 可手动设置 |
| 目标用户 | `targets` | QQ 列表 | 自动沿用当前流程，无需连线；默认收起 |

| 数据输出 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
| 判断结果 | `result` | 真假值 |  |
| 群号 | `group_id` | 群号 | 默认收起 |
| 触发用户 QQ | `user_id` | QQ 号 | 允许缺失；默认收起 |
| 目标用户 | `targets` | QQ 列表 |  |
| 目标人数 | `count` | 数值 |  |

| 参数 | 默认值或要求 |
| --- | --- |
| 匹配方式 | contains |
| 查找内容（文字匹配时必填） | 可选 |

### 消息不匹配

与消息匹配相反：未找到指定内容时走是，找到时走否。

- 执行方式：是 / 否分支
- 例如：不包含网址 → 是：继续；否：结束

| 数据输入 | 字段 | 类型 | 说明 |
| --- | --- | --- | --- |
