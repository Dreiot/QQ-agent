# 独立规则页签

规则编辑器位于主导航的「规则」，不再放在设置中。设置中的聊天与记忆相邻。每个 QQ 账号继续使用自己的规则、状态与执行记录；原有 `management` 配置及导出格式保留兼容，打开新版不会重建或清空规则。

普通成员可以选择群聊或私聊，运行消息触发、条件、计算、记录、状态、等待及回复规则。范围卡片打开统一的会话选择窗口，分别选择群聊和私聊；列表行、搜索及选择状态复用准入白名单的实现。选择自动保存，也可手动添加号码。规则名称、执行冷却以及复制、导出、删除直接显示在页面上。

机器人身份不再是整轮流程的前置门槛。踢出、禁言、撤回等具体管理操作仍单独核对管理员权限；设为管理员、取消管理员和专属头衔仍要求群主。群成员查询、群事件流与群管理操作仅支持群聊，在私聊流程中执行时明确报错，不会把私聊号码作为群号调用。QQ 原生发送限制仍由发送队列及协议端返回结果决定。

旧规则继续使用 `groups`；新增加的 `private` 保存私聊 QQ 号。实时触发、冷却、观察、旧式计数与执行记录使用带会话类型的标识，避免相同数字的群号与 QQ 号混用。消息触发节点额外输出会话类型、会话号码及会话标识，可用于条件与文本组合。定时节点也会分别为所选群聊和私聊启动流程。通用状态键仍由用户自行定义，需按会话分别保存时请把会话标识拼入键中。

新页使用独立的规则读取与保存接口。只提交规则列表，保存确认后显示浮窗，离开页签或切换账号前等待保存完成；保存失败会保留当前编辑器和重试入口。主导航、账号切换及原有图编辑能力沿用既有面板接口。

点击节点标题或内容区均可打开右侧设置，拖动仍只使用标题，接线端口不触发内容区选中。参数先显示具体来源：连入的节点及结果、固定值、触发事件资料，或当前路径选出的成员；多路来源不能静态确定时明确说明按实际到达路径合并。自动参数点击“改用固定值”后才显示输入框，恢复自动时删除该覆盖。用途、例子和内部字段名按需展开，低频参数与结果单独折叠；搜索会展开匹配项，清空后恢复之前的折叠状态。画布悬停提示和节点库复用同一份说明，不提供重复的来源下拉框和跳转按钮。已接线参数不显示未生效的旧手动值。

取值顺序与实际执行保持一致：数据连线优先于参数固定值，再取节点设置，随后才是自动来源或默认值。消息、发送者、群号等默认来自启动本轮规则的事件；普通节点临时覆盖这些参数只影响自身。选人节点才会自动改变后续路径的成员名单，多路汇合去重合并实际到达的名单。纯计算节点自动读取本轮开始资料，需要某条分支的结果时应明确接数据线。界面展示的是来源关系，上次试运行取值另作标注，不冒充真实群内的即时值。

“收起未用字段”仅切换画布视图，保留所有已接线接口，展开后可继续接线，不修改规则、布局或运行开关。试运行先显示预计操作与对象，步骤记录默认折叠；私聊隐藏群专属设置，高级样本按规则实际使用的节点展示。试运行不发送消息、不处理真实成员。

「消息纯文字」与「完整消息」分别表示文字内容和含图片、语音、@、回复等片段的整条消息；协议端以原始字符串上报时，触发节点的文字字段按原字符串处理。「群聊或私聊」的值是 `group` / `private`，「群号或对方 QQ」在群聊里是群号，私聊里是对方号码。「待处理成员」是本节点使用或选出的 QQ 名单，初始为事件相关的人，可被选人节点改变；「名单人数」是名单长度，包含后续可能被权限保护跳过的人，不代表成功操作次数。「仅处理此 QQ」指定当前成员操作的单个人，留空时处理本节点的成员名单；不是执行操作的机器人账号。

规则只使用连线画布，移除「画布 / 列表」切换及列表布局；旧的列表视图记录会恢复为画布，节点位置、缩放和平移继续保留。导出会下载包含节点、连线、字段绑定、会话范围及位置的 `qqa-management-v1` JSON 文件，文件名自动处理 Windows 不支持的字符。导出包含输入框的最新编辑，不改变原规则；导入时生成独立副本并保持停用。主窗口仅接受内置规则页导出不超过 1 MiB 的规则 JSON，不接受任意 URL 或文件路径，面板本身及第三方插件保持原有隔离。

同一用户执行冷却从本轮首次成功操作开始计时，按账号、规则、会话类型、会话和触发用户隔离。条件不匹配、只读取数据、等待或跳过受保护成员不会消耗冷却。发送、管理方法、状态写入、计数或记录说明成功后才计时；同一用户的上一轮仍在处理时仍禁止重复启动。执行前失败可重试，已经执行部分操作后再失败或取消则保留冷却。修改规则内容或换接入身份后使用新的冷却；移动节点不会清除冷却。

执行记录区分「未执行操作」「已执行」「执行失败」和「部分完成」，取消时也会提示此前是否已执行部分操作。历史版本没有操作计数的记录只显示「流程结束」，不能将旧版空 `actions` 数组误判为未执行。新增记录只保留操作次数，不增加真实消息内容或字段值的留存。
