# 独立规则页签

规则编辑器位于主导航的「规则」，不再放在设置中。设置中的聊天与记忆相邻。每个 QQ 账号继续使用自己的规则、状态与执行记录；原有 `management` 配置及导出格式保留兼容，打开新版不会重建或清空规则。

普通成员可以选择群聊或私聊，运行消息触发、条件、计算、记录、状态、等待及回复规则。范围卡片打开统一的会话选择窗口，分别选择群聊和私聊；列表行、搜索及选择状态复用准入白名单的实现。选择自动保存，也可手动添加号码。规则名称、触发冷却以及复制、导出、删除直接显示在页面上。

机器人身份不再是整轮流程的前置门槛。踢出、禁言、撤回等具体管理操作仍单独核对管理员权限；设为管理员、取消管理员和专属头衔仍要求群主。群成员查询、群事件流与群管理操作仅支持群聊，在私聊流程中执行时明确报错，不会把私聊号码作为群号调用。QQ 原生发送限制仍由发送队列及协议端返回结果决定。

旧规则继续使用 `groups`；新增加的 `private` 保存私聊 QQ 号。实时触发、冷却、观察、旧式计数与执行记录使用带会话类型的标识，避免相同数字的群号与 QQ 号混用。消息触发节点额外输出会话类型、会话号码及会话标识，可用于条件与文本组合。定时节点也会分别为所选群聊和私聊启动流程。通用状态键仍由用户自行定义，需按会话分别保存时请把会话标识拼入键中。

新页使用独立的规则读取与保存接口。只提交规则列表，保存确认后显示浮窗，离开页签或切换账号前等待保存完成；保存失败会保留当前编辑器和重试入口。主导航、账号切换及原有图编辑能力沿用既有面板接口。
