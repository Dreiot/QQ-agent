# 0.5 上游更新与本地界面迁移

本次以 `K0nd1us/QQ-agent` 的 `f079b6cca8d605789aa76b4911964ded215cec01` 为底稿，使用仓库的 `0.5(unfinished)` 目录。0.5 仍是未完成版本，本次迁移不改变其发布定位。

## 合并边界

- `src`、`bundled`、`electron`、依赖及打包清单沿用该提交；已移除的安装器、进程管理、账号扫描、专属页面和路由不会随旧界面恢复。
- 保留本地的 11 个设置页签、卡片开关、自动保存与失败重试、61 项外观设置、独立主题方案、可调连续图标动画。
- 连接设置使用 `onebot.wsUrl`、`onebot.httpUrl`、`onebot.accessToken`、`onebot.httpAccessToken`。协议端由用户自行准备，界面只配置连接地址与凭据。
- 侧栏只显示通用协议连接及模型状态；“应用日志”使用新版接口及实时日志流，并套用本地共享组件。日志级别只在本次运行生效，反馈明确显示“已应用 · 本次运行”。
- 删除已无对应功能的图标，新增日志图标；当前为 47 个绘制图标，另有未知图标回退。
- 修复组合设置页签与原始设置分区不同导致的快捷入口失效，以及日志旧刷新回执覆盖新级别选择的竞态。

## 验证范围

迁移相关检查覆盖通用 OneBot 边界、连接恢复、身份状态、实时事件、日志流、实际字段保存及失败重试、设置布局、主题存储和编辑、图标逐帧边界及动效生命周期。布局验收包含 11 页签 × 4 个窗口宽度；新增迁移集成验收覆盖连接页和日志页的桌面、窄屏显示。

验收使用隔离数据和合成本地服务，不以此声称真实 QQ 或外部模型已连通。完整 M3 套件未通过本次全量验收；部分历史测试仍包含旧页签结构、手动保存等断言。

本地迁移备份、上游快照、校验清单和测试证据保存在被 Git 忽略的 `.qa-local/upstream-migration-20261024/`。该目录不进入应用打包。
