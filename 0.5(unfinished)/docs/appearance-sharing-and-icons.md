# 外观共享与图标自定义

在“设置 → 外观 → 更换图标”选择要修改的图标，再选择内置图形或上传图片。导航、设置、操作、连接状态、空内容提示与展开箭头使用同一套图标配置；现有 49 种系统图标均有名称、预览和恢复默认入口。修改立即预览并自动保存。支持 PNG、JPG、WebP、GIF，以及不含脚本、样式或外部引用的纯图形 SVG；单张图片最多 140 KB。

选择器按“导航、操作、状态、其他”分类，搜索会跨分类查找。左侧使用等宽选择卡片，右侧显示大预览；内置图形也可按类别筛选或查看全部。缩略图卡片的布局独立于普通操作按钮的尺寸设置，紧凑外观不会将它们挤小；窄窗口下预览改为上下排列。

## 共享范围

- **所有账号共享**：字体、字号、布局、尺寸、留白、圆角、控件风格、一般动效、普通图标，以及点选编辑中的非颜色样式。切换亮色、暗色或自定义配色时，共享的布局与字体保持一致。
- **按账号独立**：配色、背景图片或视频及其取景参数、左上角图标及其大小和运动速度。点选编辑中的文字色、底色、描边色、填充色和阴影保留在各账号。已有 QQ 的模型、规则、响应范围和其他业务设置不参与共享。

首次启用时，没有绑定 QQ 的内部工作区优先沿用已保存且启用的 QQ 外观作为共享起点；已有共享配置时不重新初始化。停止的账号下次连接会接收最新共享设置。已有配色、背景和左上角图标不被其他账号覆盖。

共享状态由客户端宿主统一持久化，工作进程仅传递经过主题字段筛选的外观差量，不传模型密钥、协议令牌或其他配置。多个账号同时调整不同项目时按差量合并。保存结果等待宿主确认；写入失败可重试，不把只存在于内存中的状态当作已保存。对普通图标的替换也会更新已显示和随后创建的图标，无需重启；上传的图片在本地使用，不会从外部网址读取。

## 连接后直接查看

账号经过原生协议端、HTTP、WebSocket 与 QQA 工作进程核验后，接入窗口自动关闭，客户端直接查看该账号，保留当前页签。切换使用本次核验的最新账号列表，并作废此前未完成的旧列表请求，避免被缓存的“未连接”状态挡回账号管理。未完成、失败或取消的接入不会切换账号。
