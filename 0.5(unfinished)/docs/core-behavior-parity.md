## 旧技能的实际装载与执行

compat-04默认适配器将旧parameters映射为params，旧execute(ctx,args)映射到当前工具顺序；显式现代params不反转。setup/register与声明providers/hooks同时登记，不再被else-if互斥。loader先接管适配实例再执行setup，成功后保留该实例，初始化失败能清理，重载失败能恢复旧工具/能力与生命周期。

旧回调只获得窄兼容API及reason/skillId元数据，不返回新版内核ctx；同代生命周期防重复。旧isError保留失败标记，payload、文本与媒体均保留；runner把真实工具返回的媒体统一收集为user parts，失败工具不会因此变成成功。该路径不额外下载或发送媒体，也不宣称替任意第三方ToolResult新增字节校验。原注册表权限、指纹、代际与SDK授权保持。
