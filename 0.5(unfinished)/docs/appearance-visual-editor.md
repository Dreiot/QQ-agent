# 外观点选编辑

在「设置 → 外观」点击 **点选编辑**，直接调整当前页面。编辑器显示在页面旁边，调整即时预览，停止输入后自动保存；保存失败时会保留草稿并显示重试入口。

外观首页默认只显示配色和三个联动调整：**文字大小、页面疏密、圆润程度**。它们会一起协调相关控件；完整的原始参数仍在“精细调整”里。试用控件、背景和主题管理按需展开。

在“背景”选择图片、动图或 MP4/WebM 视频，可拖动选区、旋转并自动保存。取景框、预览和实际背景始终采用当前应用窗口的宽高比，窗口改变大小时实时更新；缩放窗口不会修改配置、重新导入文件或重启视频。文件按原始字节导入，不缩小、不转码，单文件最多 256MB；大文件分段传输，传输进度或错误在按钮旁显示。视频默认静音、自动循环，页面隐藏时暂停，恢复可见后继续；折叠编辑器时停止预览播放，调整主题不会重建主背景播放器。视频支持铺满与完整显示，图片另有平铺。若原先不透明度为 0%，选新背景时恢复为 20%；其它不透明度设置保留。

点中元素后，先从样式卡片选择效果。按钮有实心、细边、柔和、轻盈等样式；卡片、文字、图片和图标各有适合自己的样式。默认只显示四个，需要时点击“更多样式”。移入或聚焦卡片会临时预览，并标明“预览”；点击才应用和保存。

样式、大小或留白、圆润程度可以独立搭配。选新样式会保留已设置的尺寸、布局和间距；每次选择可用一次撤销恢复。预设配色跟随当前主题，后续改强调色时会一起变化；手动选取的具体颜色则保持独立。

1. 点选按钮、文字、输入框、卡片或图片。按住 **Shift** 可以精确选中按钮内部的图标和文字。
2. 选择范围：**仅此元素**、**本页同类**或**所有同类**。未选中的范围保持普通颜色。
3. 常用调整直接显示；需要时展开“精细调整”，可编辑颜色与不透明度、尺寸、内外边距、字体、四个角、阴影、布局、图片与图标等。尺寸支持像素、百分比和视口单位；字体可以输入本机安装的字体名称。
4. 拖动选中框的右下角调整尺寸，也可聚焦该手柄后用方向键微调。选择 **外层** 可以调整整个卡片或弹窗。
5. 默认、悬停、按下、聚焦与禁用状态分别设置、分别预览，不需要实际执行按钮动作。
6. 从编辑器顶部选择其他页面。点击 **浏览页面** 或按住 **Alt** 可以正常操作页面、打开弹窗，再继续点选。Esc 暂停点选，再次 Esc 退出。

**撤销 / 重做**保留最近 50 步；每个属性均可恢复继承值。通过 **已有样式** 查找、调整或移除规则；即使元素已被隐藏，也能在此恢复。恢复全部元素样式不会改变原有全局配色。元素样式可以单独导入、导出，导入也可撤销。

样式跟随当前账号和当前主题，另存主题时一起复制。原来的全局主题、背景、图标与动效设置继续保留。规则只描述外观，不保存输入值、聊天文本或凭据。

动态列表的项目顺序可能变化，调整列表外观优先选择“本页同类”；针对当前弹窗创建的样式会在该弹窗下次出现时继续生效。原生系统窗口和第三方协议端页面不属于 QQA 的页面样式范围。

编辑时仅增量更新样式表，拖动按浏览器帧合并；退出点选后停止选取监听与观察，不持续扫描页面。样式内容经过属性、选择器、数值和颜色校验，不执行脚本或加载远程 CSS。
